# Harcama Defteri

Kategorili, ay ay harcama takibi: bütçe, sabit giderler, şahsi/şirket ayrımı, arama, yıllık özet ve CSV çıktısı.
Kart ekstresi PDF'lerini telefonda, internetsiz okur (VakıfBank, QNB, İş Bankası Maximiles); daha önce girilmiş harcamaları ayıklar.
Veriler yalnızca kullanan kişinin telefonunda saklanır; sunucuya hiçbir şey gönderilmez. İnternetsiz de açılır.

Telefona kurmak için: bu sayfanın adresini iPhone'da Safari ile aç → Paylaş → Ana Ekrana Ekle.

PDF okuma için Mozilla pdf.js kullanılır (vendor/, Apache 2.0 lisansı: vendor/LICENSE-pdfjs.txt).
